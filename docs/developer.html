Write an add-on

An add-on is a folder with manifest.json and main.js. It draws pages in the open island and short events beside the closed one.

  1. Turn on Developer Mode

    In Settings, open Developer. While it's off, no add-on is read, run or shown.

  2. Create one

    Press Create. A starter add-on appears, switched on, with its folder open in Finder at ~/Library/Application Support/DynamicBar/AddOns/.

  3. Edit main.js

    Call DynamicBarKit.page to draw. With Live reload on, saving restarts the add-on. The console in Settings shows logs, errors with line numbers and layout warnings.

  4. Add settings and permissions

    Settings declared in the manifest become controls in the add-on's row. Permissions are asked for the same way.

  5. Share it

    Export a .dbaddon from the add-on's menu. Whoever installs it sees what it asks for first.

Layout rules

        
    
          
  • Never place anything in the notch. The safe area is added for you.
    • 
          
  • Use a vstack or hstack as the root, and put long content in a scroll.
    • 
          
  • Need more room? Pass { height, width } to page: up to 320 tall and 600 wide.
    • 
          
  • Text sits on dark glass: white by default, opacity 0.55 for secondary lines, 11 pt or larger.
    • 
          
  • Scripts run on the main thread. Use timers, never long loops, and pause in onClose.
    •
